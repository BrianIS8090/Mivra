### Меню-бар (рендерится в App между TitleBar и Toolbar)

Пункты верхнего уровня: Файл, Правка, Вид, Плагины, Сервис, Справка.
Поведение: клик открывает выпадающее меню; при открытом меню hover по соседнему топ-пункту
переключает меню (как в десктопных приложениях); Esc закрывает (с preventDefault — координация
со слоями, как в F1); клик вне закрывает; aria: role menubar/menu/menuitem.
Клавиатура: Up/Down по пунктам, Left/Right между топ-меню, Enter активирует — по возможности
(не в ущерб простоте; если усложняет — задокументировать пропуск).

Содержимое (шорткаты подписаны справа в пунктах и работают как раньше — глобальный keydown в App):
- **Файл**: Открыть… Ctrl+O · Недавние ▸ (подменю: до 10 пунктов из recentFiles, клик = openPath
  из useFile; пусто — неактивный пункт recentFilesEmpty) · разделитель · Сохранить Ctrl+S ·
  Сохранить как… Ctrl+Shift+S · Обновить с диска (reload; disabled когда filePath == null) ·
  разделитель · Печать… Ctrl+P.
- **Правка**: Найти… Ctrl+F · Заменить… Ctrl+H — оба открывают панель поиска (та, что из F1).
  Состояние searchOpen сейчас живёт в App — App передаёт MenuBar колбэки onFind/onReplace
  (открыть панель / с раскрытой заменой).
- **Вид**: Тема ▸ (Светлая/Тёмная/Системная — отметка ✓ на активной, toggleTheme/setTheme из
  useTheme — посмотреть, что есть в хуке; если есть только toggle — использовать его или расширить
  точечно) · Режим редактора (переключает Визуальный/Исходный, Ctrl+/).
- **Плагины**: перенести целиком текущее содержимое плагин-меню из Toolbar (кнопки плагинов из
  pluginStore + Менеджер плагинов). Владение PluginManagerDialog переезжает в MenuBar.
- **Сервис**: Настройки S3… (открывает S3SettingsDialog — владение диалогом переезжает в MenuBar) ·
  Автосохранение ✓ (чекбокс-пункт, переключает autosave из стора) · Язык ▸ (Русский / English,
  ✓ на активном).
- **Справка**: Справка (открывает HelpDialog — владение переезжает в MenuBar) · О программе
  (HelpDialog с активной вкладкой «О программе», если такое уже поддерживается — проверить пропсы
  HelpDialog; если нет — только «Справка», без дублирования функционала).

### Тулбар (после слимминга)

Остаются ТОЛЬКО: выбор шрифта, размер (−/+), ширина страницы, переключатель режима, тоггл
«Автосохранение». Удаляются: Открыть, Недавние, Сохранить, Сохранить как, Печать, ↻, тема,
меню Плагины, S3, Справка, RU — их функциональность теперь в меню-баре. Стили/классы, ставшие
мёртвыми, не трогать в toolbar.css, если они используются меню-баром (поповер-паттерн переиспользовать).

### Статус-бар (индикаторы)

В правую часть (перед счётчиком слов): индикатор `S3 ✓` когда `s3 && s3Verified` (title — bucket),
и индикатор автосохранения (ключ `statusAutosaveOn`) когда `autosave === true`. Скрыты, когда выкл.
